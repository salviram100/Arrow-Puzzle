Arrow Puzzle

Native Android game (Kotlin + Jetpack Compose, Room) — 100 stages, custom stage editor, arrow-vector puzzle engine and 3-star ratings.

Why this page and not the game itself: this project builds an Android app, so its UI cannot run in a browser.
